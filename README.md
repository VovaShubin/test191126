# Проверка скорости скачивания

Консольный скрипт выполняет 10 последовательных HTTP(S)-запросов к указанному
адресу. Каждый следующий запрос начинается только после полного получения
предыдущего ответа.

Скрипт выводит время и объём каждого ответа, а затем:

- среднее время одного запроса в секундах;
- общий объём скачанных тел ответов в мебибайтах (МиБ, 1 МиБ = 1 048 576 байт);
- среднюю скорость скачивания в МиБ/с.

## Требования

Node.js 16 или новее. Внешние зависимости не нужны.

## Запуск

```bash
node download-speed.js "https://example.com/large-image.jpg"
```

URL должен начинаться с `http://` или `https://`. HTTP-перенаправления
поддерживаются.
